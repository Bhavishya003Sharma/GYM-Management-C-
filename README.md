# Gym Management System (C++)

A console-based Gym Management System developed in C++ using Object-Oriented Programming (OOP) concepts and file handling. The project manages gym members, trainers, attendance records, and member data through a menu-driven interface.

## Features

* Add and manage gym members
* Add trainer details
* Generate unique member IDs
* Attendance tracking system
* Store records using text files
* View member details
* Delete member records
* Interactive console interface

## Concepts Used

* Classes & Objects
* Inheritance
* Constructors
* Encapsulation
* File Handling
* String Manipulation
* Menu-Driven Programming

## Technologies Used

* C++
* fstream
* OOP Concepts

This project was built to practice practical implementation of C++ and Object-Oriented Programming concepts.
